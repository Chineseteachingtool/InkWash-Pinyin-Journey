# 墨韻拼音行 InkWash Pinyin Journey

一款 2.5D 中國水墨風格的網頁 RPG：玩家在山水長卷中與人物對話，闖過 14 道拼音小遊戲，從零基礎修練成拼音專家。
A 2.5D Chinese ink-painting web RPG: talk to characters across an ink-wash scroll and clear 14 pinyin mini-games to go from beginner to Pinyin Expert.

**線上遊玩 Play online:** https://chineseteachingtool.github.io/InkWash-Pinyin-Journey/

## 四大區域 Four areas
| 區域 Area | 學習階段 Stage | 難度 | 關卡 Challenges |
|---|---|---|---|
| 啟蒙村 Primer Village | 基礎認識期 Recognition | 零基礎 Beginner | 亂序閃卡快答、聽音指認、聲調體操、拼音打地鼠 |
| 書院 Academy | 拼讀建立期 Blending | 初級 Elementary | 隨機組合拼讀、拼音大轉盤、幫聲調找家 |
| 辨音山 Echo Mountain | 易錯突破期 Tricky Sounds | 中級 Intermediate | 最小對立組聽辨、拼音分類帽、ü 的魔術帽、雙字詞聽寫與變調 |
| 藏書閣 Library Tower | 精熟應用期 Fluent Use | 精熟 Mastery | 純拼音短文朗讀、純拼音尋寶任務、拼音小信差 |

## 特色 Features
- 與人物對話觸發遊戲，對話框顯示難度並詢問是否開始 / Dialog shows difficulty and asks before each challenge
- 經驗值、等級稱號、「通」字印與拼音掌握度檢核表 / XP, titles, mastery seals and a progress checklist
- 自動存檔（瀏覽器 localStorage）＋可跨裝置的存檔碼 / Auto-save in the browser plus a portable save code
- 中文／English 介面切換 / Chinese / English interface toggle
- 使用瀏覽器內建中文語音（建議 Chrome、Edge、Safari）/ Uses the browser's built-in Chinese voice

## 操作 Controls
方向鍵／WASD 移動，空白鍵交談，也可直接點擊地面或人物。
Arrow keys / WASD to move, Space to talk, or click the ground and characters.

整個遊戲是單一 `index.html`，不需要安裝或建置。 The whole game is a single `index.html` with no build step.
